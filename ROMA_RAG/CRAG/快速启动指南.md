## ⚡ 快速启动步骤

### 方式一：使用现有数据快速测试

如果您已经有预处理好的数据，可以直接运行推理：

```bash
# 1. 激活环境
conda activate CRAG

# 2. 进入脚本目录
cd CRAG/scripts

# 3. 运行CRAG推理（使用示例配置）
python CRAG_Inference.py \
  --generator_path /path/to/your/llm/model \
  --evaluator_path /path/to/evaluator/model \
  --input_file ../data/popqa/test_popqa.txt \
  --output_file ../data/popqa/output/test_output.txt \
  --internal_knowledge_path ../data/popqa/ref/correct \
  --external_knowledge_path ../data/popqa/ref/incorrect \
  --combined_knowledge_path ../data/popqa/ref/ambiguous \
  --task popqa \
  --method crag \
  --device cuda:0 \
  --ndocs 10 \
  --upper_threshold 0.592 \
  --lower_threshold 0.995
```

### 方式二：完整流程（从数据预处理开始）

```bash

# 步骤3：运行推理
python CRAG_Inference.py [参数同上]
```

## 🛠️ 简化配置脚本

创建 `config.sh` 文件：

```bash
#!/bin/bash

# 模型路径配置
export GENERATOR_PATH="/path/to/llm/model"
export EVALUATOR_PATH="/path/to/evaluator/model"

# API密钥配置
export OPENAI_KEY="your-key-here"
export SEARCH_KEY="your-key-here"

# 数据集配置
export DATASET="popqa"

# 阈值配置
export UPPER_THRESHOLD=0.592
export LOWER_THRESHOLD=0.995
```

然后在运行脚本中使用：

```bash
source config.sh
python CRAG_Inference.py \
  --generator_path $GENERATOR_PATH \
  --evaluator_path $EVALUATOR_PATH \
  ...
```

## ❓ 常见问题快速解决

### Q: 如何知道CRAG是否生效？

A: 对比 `--method rag` 和 `--method crag` 的输出结果和评估分数

### Q: 没有GPU可以运行吗？

A: 可以，使用 `--device cpu`，但速度会慢很多

### Q: 如何调整阈值？

A: 根据评估器输出的置信度分数分布调整，通常：
- 高阈值（0.5-0.7）：更严格，更多使用外部知识
- 低阈值（0.9-1.0）：更宽松，更多使用内部知识

### Q: 可以只使用内部知识准备吗？

A: 可以，只运行 `internal_knowledge_preparation.py`，然后在推理时只使用 `--internal_knowledge_path`
